# FindBack AI brand spec

## Identity

- **Product name:** FindBack AI
- **Tagline:** Lost something? Let AI help you FindBack.
- **Tone:** calm, practical, intelligent, community-first, privacy-aware
- **Mark:** a rounded tilted square with an orange signal dot; implemented as the compact `.brand-icon` in the frontend so the mark stays crisp at small sizes

## Visual tokens

- **Canvas:** `#F7F8F4`
- **Ink navy:** `#14252D`
- **Deep navy:** `#10262D`
- **Signal orange:** `#E86433`
- **Signal orange dark:** `#C8481D`
- **Soft orange:** `#FFF0E9`
- **Community green:** `#4B9B76`
- **Soft green:** `#E5F2EA`
- **Border:** `#DFE5E2`
- **Spacing:** 12px rhythm with 8px control gaps
- **Cards:** 18px radius for primary cards, 10px for controls
- **Elevation:** soft, low-opacity shadows; no heavy glassmorphism

## Typography

- **Display / UI headings:** Space Grotesk 500–700
- **Body:** Manrope 400–800
- **Metadata / labels:** DM Mono 400–500

## Motion

- Short ease-out transitions using `cubic-bezier(.23,1,.32,1)`
- Buttons confirm input with a small active scale
- Reduced-motion users receive near-zero animation durations
